\chapter{物理样机实验验证}\label{chap:experiment}

本章基于已搭建的混合式双轮足机器人样机开展物理实验。实验内容围绕原地平衡、速度跟踪、滚转稳定和腿长控制四类典型工况展开，重点考察 LQR 主控制器、VMC 腿长支撑控制器以及滚转稳定环节在实物平台上的协同作用。实验记录的状态量包括机体俯仰角 $\theta_b$、滚转角 $\gamma$、前进速度 $\dot{s}$、左右虚拟腿长 $l_l,l_r$、轮端力矩 $T_{lw,l},T_{lw,r}$ 以及腿部关节力矩 $\tau_l,\tau_r$。其中，俯仰角与前进速度主要用于评价 LQR 控制器的平衡和速度调节能力；左右腿长、腿长误差和关节力矩用于评价 VMC 的支撑控制效果；滚转角和左右腿长差则用于分析滚转稳定环节的作用。

\section{物理样机平台介绍}

实验样机由机械本体、驱动系统、传感系统、嵌入式控制系统和上位机记录系统组成。机械部分沿用第二章提出的混合式双轮足结构，左右腿均采用对称闭环连杆机构，足端安装轮毂电机。腿部关节电机布置在靠近躯干的位置，并通过链传动驱动连杆运动，从而在保证腿部运动范围的同时减小末端转动惯量。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.8\textwidth]{figures/ch05/demo.png}
  \caption{物理样机实物图}
\end{figure}

控制器运行在嵌入式主控板上。主控板选用 STM32H723，主频为 $480\,\mathrm{MHz}$，能够满足本文控制算法的实时运行需求。在每个控制周期内，主控板首先读取惯性测量单元、轮毂电机编码器和腿部关节编码器数据，并根据第四章的状态估计方法计算机体姿态、前进速度、虚拟腿长和腿摆角。随后，控制程序计算 LQR 轮端力矩与腿摆控制量、VMC 腿长支撑力和滚转稳定量，并将力矩指令发送至各电机驱动器。

传感系统主要包括惯性测量单元和电机编码器。惯性测量单元安装在机体中部附近，用于测量机体俯仰角、滚转角及其角速度。轮毂电机编码器用于估计左右轮角速度和机器人前进速度。腿部关节编码器结合第三章建立的五连杆运动学模型，可实时解算左右虚拟腿长和腿摆角。实验过程中，上位机通过无线烧录器保存关键状态量，并在实验结束后进行离线绘图与数据分析。

实物实验采用与第四章一致的分层控制结构。LQR 控制器负责机体俯仰平衡、速度调节和腿摆控制量分配，VMC 控制器负责腿长方向的支撑与高度调节，滚转稳定环节根据测得的滚转角修正左右腿长参考值。与仿真环境相比，实物平台中的执行器带宽、地面接触和传感器噪声均会引入额外不确定性，因此控制参数不能完全直接照搬仿真结果，而需在保证安全性的前提下进行小幅调整。

具体调试过程中，首先在离线模型中求解 LQR 增益矩阵，并在实物样机上以较小输入限幅完成低幅度站立测试；随后逐步提高轮端力矩限幅和姿态反馈增益，使机器人能够在初始姿态偏差下恢复平衡；在主平衡闭环稳定后，再调节 VMC 腿长刚度 $K_l$ 与阻尼 $D_l$，使腿长响应具备足够支撑能力且不产生明显振荡；最后开启滚转稳定，并通过腿长差限幅抑制由滚转角噪声引起的左右腿高频抖动。

实验均在平整地面上进行。每组实验重复多次，并在离线分析时剔除通信中断、保护架碰撞、轮端离地等异常片段。各实验的评价指标如下：

\begin{enumerate}
  \item 原地平衡实验：观察机体俯仰角和腿摆角是否收敛，前进速度是否回到零附近，以及轮端力矩是否出现长期饱和；
  \item 速度跟踪实验：观察实际速度相对参考速度的响应滞后、稳态误差和超调情况，同时检查速度变化过程中机体姿态是否保持稳定；
  \item 滚转稳定实验：观察滚转角峰值、恢复过程和左右腿长参考差异，分析滚转稳定对侧向姿态的改善作用；
  \item 腿长控制实验：观察左右实际腿长对参考腿长的跟踪能力、两侧响应一致性以及高度变化对整机平衡的影响。
\end{enumerate}

\section{原地平衡性能验证}

原地平衡是双轮足机器人开展其他运动实验的基础。实验中，左右腿参考长度均设为基准腿长，期望前进速度取 $\dot{s}_d=0$，偏航角和腿摆角参考值取零。样机由初始支撑状态进入直立状态后，LQR 控制器根据俯仰角、俯仰角速度和轮系状态输出轮端力矩，使机器人通过小范围前后移动维持倒立摆平衡；VMC 控制器则维持左右腿长在基准值附近，为机体提供稳定支撑。

原地平衡实验结果如\figref{fig:balance-experiment-response} 所示。实验初期，机器人由非平衡姿态向直立姿态过渡，前进速度和腿摆角均出现较大瞬态变化。随后，左右腿摆角逐渐收敛到零点附近，且收敛后未出现持续增大的低频摆动，说明 LQR 控制器能够有效抑制腿摆方向的姿态偏差。前进速度在起立阶段快速下降，并在平衡阶段保持在较小范围内波动，表明机器人能够在不产生明显持续位移的情况下维持站立。

从轮端力矩曲线可以看出，起立初期左右轮电机输出方向相反且幅值较大，这是控制器为了修正机体姿态所产生的瞬态调节作用。进入平衡阶段后，两侧力矩逐渐减小并围绕零附近波动，未出现长时间饱和现象，说明执行器输出能力能够满足原地平衡需求。左右轮端力矩的整体变化趋势较为对称，也表明样机两侧传动阻力和控制响应不存在显著失衡。综合来看，所设计的 LQR-VMC 控制结构可以在物理样机上实现稳定原地平衡。

\section{速度跟踪性能验证}

速度跟踪实验用于验证 LQR 控制器在速度调节和机体姿态稳定之间的协调能力。实验中，机器人先完成原地平衡，随后给定分段常值的速度参考。为降低速度指令突变对轮端摩擦和机体姿态的冲击，程序中对速度参考加入斜坡限幅。

\begin{figure}[H]

  \caption{速度跟踪实验响应曲线}
  \label{fig:velocity-experiment-response}

速度跟踪实验结果如\figref{fig:velocity-experiment-response} 所示。当速度参考由负向或零附近逐渐切换至正向时，实际速度能够跟随参考速度变化，并在加速阶段呈现连续上升趋势。由于实物样机存在轮地摩擦变化、电机响应滞后和速度估计滤波延迟，实际速度相对于参考速度存在一定滞后，且在参考速度变化较快时会出现短时跟踪误差。该现象符合物理平台的实际运动特性。

在速度调节过程中，左右腿摆角变化趋势基本一致，说明机器人主要以整体前后倾姿态配合轮端驱动力完成加减速，而未出现明显的单侧腿摆失衡。当速度参考从正向切换至反向时，腿摆角随之减小并出现短时反向偏转，这是双轮倒立摆系统在减速和反向运动过程中的正常姿态响应。轮端力矩曲线在速度变化阶段出现较明显波动，反映出控制器需要通过较大的瞬态驱动力克服惯性并修正姿态；当速度参考变化趋缓后，力矩幅值随之降低。


\section{滚转稳定性能验证}

第三章建立的主动力学模型主要描述机器人前进方向、腿摆和机体俯仰之间的耦合关系，并未将滚转角直接纳入 LQR 主控制器。实际样机在侧向扰动、转向或左右支撑高度不一致的情况下，机体会产生滚转角偏差，进而导致左右腿支撑状态不同。本节通过滚转稳定实验验证第四章提出的基于腿长差修正的侧向稳定方法。

实验中，样机在保持主平衡控制闭环的同时开启滚转稳定。滚转稳定根据测得的机体滚转角和当前腿部几何关系，计算左右腿期望腿长差，并将其叠加到左右腿长参考值中。与直接构造侧向力矩的方法相比，该补偿方式不改变 LQR-VMC 主控制框架，仅通过调整左右支撑几何关系抑制机体侧倾，因而具有实现简单、计算量小的特点。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.8\textwidth]{figures/ch05/roll_compensation.png}
  \caption{滚转稳定前后实验响应对比}
  \label{fig:roll-experiment-response}
\end{figure}

滚转稳定实验结果如\figref{fig:roll-experiment-response} 所示。实验过程中，机体滚转角在扰动作用下出现明显偏移，随后逐渐回到零点附近。与此同时，左右腿长参考值不再保持完全相同，而是根据滚转角变化形成相反方向的修正量。该现象说明滚转稳定环节已经参与腿长通道控制，并能够通过改变左右腿支撑高度对机体侧倾进行修正。

从左右腿长曲线可以看出，实际腿长能够跟随补偿后的参考腿长变化，但存在一定响应滞后。这主要与腿部执行器带宽、闭环连杆传动间隙以及 VMC 刚度阻尼参数有关。当参考腿长差变化较快时，实际腿长曲线相对于指令曲线出现延迟和局部平滑化，说明腿部机构对高频补偿指令具有一定滤波作用。该特性有利于避免滚转角噪声直接引起左右腿抖动，但也会限制滚转稳定对快速侧向扰动的抑制能力。

总体而言，实验结果表明，基于腿长差修正的滚转稳定能够在不改变主控制框架的前提下改善样机侧向姿态。该方法适合用于平地低速运动和轻微侧向扰动场景，但对于高速转向、强侧向冲击或复杂三维地形，仍需结合更完整的侧向动力学模型和接触力分配策略进一步优化。

\section{腿长控制验证}

腿长控制实验用于验证 VMC 腿长通道在物理样机上的高度调节和支撑能力。实验中，机器人首先保持原地平衡，随后给定左右腿公共腿长参考 $l_d$ 的周期性升降指令，并记录左右实际腿长的跟踪过程。该实验不额外改变 LQR 主控制律，腿摆方向仍由 LQR 输出控制量，因此可以较为独立地观察 VMC 腿长控制对机体高度变化的影响。

腿长控制实验结果如\figref{fig:leg-experiment-response} 所示。左右腿参考长度在低位和高位之间周期性变化，实际腿长能够按照参考指令完成伸长和缩短，说明第三章建立的腿部运动学解算与第四章设计的 VMC 控制律能够在实物样机上形成有效闭环。两侧腿长响应趋势基本一致，表明左右腿机构装配和驱动参数具有较好的一致性。

从跟踪细节看，实际腿长相对于参考腿长存在一定相位滞后，在腿长快速上升或下降阶段尤为明显。该滞后主要来源于电机响应、链传动间隙、腿部连杆惯量以及参考指令限幅等因素。高位和低位保持阶段，实际腿长能够稳定在参考值附近，未出现持续振荡，说明虚拟弹簧阻尼参数能够在响应速度和稳定性之间保持较合理的折中。若进一步提高腿长刚度，理论上可以缩短响应时间，但也可能增大关节力矩峰值并引入结构振动；若过度增大阻尼，则会降低腿长调节速度。因此，实际调参需要同时考虑跟踪误差、关节力矩和机体姿态变化。

腿长调节过程中，机器人仍能维持基本平衡，说明 VMC 腿长通道与 LQR 主平衡控制之间没有产生明显冲突。该结果验证了本文采用“全局平衡与局部支撑解耦”的分层控制思路，即 LQR 负责维持倒立摆姿态稳定，VMC 负责调节腿长和支撑高度，两者通过任务空间力矩映射共同作用于腿部执行器。

\section{本章小结}

本章围绕混合式双轮足机器人物理样机开展实验验证。首先介绍了样机平台的机械结构、驱动系统、传感器配置、嵌入式控制系统和数据记录方式，并说明了控制参数调试流程与实验评价指标。随后，分别通过原地平衡、速度跟踪、滚转稳定和腿长控制实验，对 LQR 主控制器、VMC 腿长支撑控制器以及滚转稳定环节进行了实物验证。

实验结果表明，样机能够在初始姿态偏差下完成起立并保持原地平衡，轮端力矩未出现长期饱和；在速度跟踪实验中，实际速度能够随参考速度变化，尽管受到执行器滞后、轮地接触和速度估计噪声影响，仍能保持机体姿态稳定；滚转稳定实验表明，通过左右腿长差修正可以改善机体侧向姿态；腿长控制实验则验证了 VMC 腿长通道对周期性高度指令的跟踪能力。

同时，实物实验也暴露出样机平台相较仿真环境的局限性，包括传动间隙导致的腿长响应滞后、轮地接触变化造成的速度估计波动以及滚转稳定对快速侧向扰动响应有限等问题。这些现象为后续进一步优化结构刚度、提升执行器带宽、完善状态估计和引入更完整的三维稳定控制方法提供了依据。
